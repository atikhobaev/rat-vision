# 🐀 RAT VISION v1.2.0-beta.1

> 🧪 **Public beta — Windows/NVIDIA hardware feedback welcome.**

## 🛡️ Display output, not a cheat
RAT VISION changes display-output settings such as gamma, brightness, contrast and NVIDIA Digital Vibrance. It does **not** inject code, read/write game memory, modify game files or automate input.

## ✨ Highlights
- 🎮 Automatic per-game/application display profiles
- 🌐 Global desktop fallback profile
- 🖥️ Multi-monitor targeting + Windows friendly monitor names
- 🌗 Gamma / ☀️ brightness / ◐ contrast / 🎨 NVIDIA DVC
- 🐀 Tray mode and polished Level Black / Clean Lab UI
- ❔ Tutorial tour and contextual tooltips
- 🔄 GitHub Releases update protocol with SHA-256 verification
- 📊 Pseudonymous usage analytics — ON by default in configured builds, with Settings opt-out
